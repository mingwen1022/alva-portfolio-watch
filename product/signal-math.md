## 一、记号与窗口

$$r_t=\frac{c_t}{c_{t-1}}-1\qquad\text{（简单收益，不取对数）}$$

$c_t$ 收盘价 · $V_t$ 成交量 · $n$ 全部可得根数

| 常量 | 值 | 含义 |
|---|---|---|
| $W$ | 90 | 滚动基线窗口（日线用交易日，盘中用「同一时刻」的天数） |
| $F$ | 5 | 前瞻窗 |
| $B$ | 20000 | 自助重采样次数 |
| $\theta_z$ | 1.5 | 日线价格阈值，两类资产相同 |
| $\theta_v$ | 2.0 美股 / 3.0 加密 | 日线量能阈值 |
| $\theta_z^{\text{bar}}$ | 4.75 美股 / 10.0 加密 | 盘中价格阈值 |
| $\theta_v^{\text{bar}}$ | 2.0 美股 / 3.0 加密 | 盘中量能阈值 |

⚠️ **所有基线窗口一律「前 $W$ 期，不含当期」。** 把当期算进自己的基线，
等于把要判它的那个分母撑大 —— 越极端的一天被压得越狠。

## 二、M 层 · 基础量

### M2 · 稳健 z

$$\mathrm{med}_t=\operatorname{median}(r_{t-W},\dots,r_{t-1})$$

$$\mathrm{MAD}_t=\operatorname{median}\big(|r_{t-W}-\mathrm{med}_t|,\dots,|r_{t-1}-\mathrm{med}_t|\big)$$

$$\sigma^{\mathrm{rob}}_t=1.4826\cdot \mathrm{MAD}_t
\qquad
z_t=\frac{r_t-\mathrm{med}_t}{\sigma^{\mathrm{rob}}_t}$$

**1.4826 是按正态校准的常数** —— 它让 $1.4826\cdot\mathrm{MAD}$ 在正态分布下等于标准差。
用中位绝对偏差而不是普通标准差，是因为一个极端值撑不大中位数。

⚠️ **这个常数也是 $\rho$ 检验存在的理由**：分布形状一偏，$z$ 的量纲就变了。
均匀分布下 $\max|z|=1.35<1.5$，PV1 永远不会触发，**而且是静默的**。见 §九。

### M3 · 相对量

$$\mathrm{RVOL}_t=\frac{V_t}{\operatorname{median}(V_{t-W},\dots,V_{t-1})}$$

### M4 · 年化波动

$$\sigma^{\mathrm{ann}}_t=\sigma^{\mathrm{rob}}_t\sqrt{A},\qquad A=252\ \text{股}\ /\ 365\ \text{币}$$

只用于 `degraded` 判定（美股 $>50\%$ · 加密 $>92.8\%$）。

⚠️ **`degraded` 只压投递、不改触发，且对 US1–3 不适用** —— 见 output-schema §`delivery`。

## 三、S 层 · 触发式

### PV1 · 日线

$$\text{PV1}_t \iff |z_t|\ge\theta_z\ \ \wedge\ \ \mathrm{RVOL}_t\ge\theta_v$$

### PV5 · 盘中 15 分钟

$$\text{PV5}_b \iff |z^{\text{bar}}_b|\ge\theta_z^{\text{bar}}\ \ \wedge\ \ \mathrm{RVOL}^{\text{bar}}_b\ge\theta_v^{\text{bar}}$$

**分母取「同一时刻」的前 90 天**，不是前 90 根。设 $S(b)$ 是与 $b$ 同一分钟槽位的历史 bar：

$$z^{\text{bar}}_b=\frac{r_b-\operatorname{median}\big(r_j : j\in S(b)_{-90}\big)}
{1.4826\cdot\operatorname{MAD}\big(r_j : j\in S(b)_{-90}\big)}$$

⚠️ **开盘和收盘那几根本来就比午盘大**，混排会把它们全判成异常。
同一时刻样本不足 30 天不出读数。美股只算常规交易时段，加密算全天。

## 四、一条真触发从头到尾

用 acct1 线上 **DOGE 在 2026-08-21** 的真实记录，每一步都可以拿产物核对。
它同一天既触发了 PV1 也触发了 PV5，正好能看清两者用的是**两套不同的基线**。

### 初始化时算了什么

```
init.js  一次性，此后不再重跑
├─ 取日线                     502 根（约两年）
│  └─ σ 的五步（展开见下）      = 0.015064   → baselines.DOGE.sigmaRobust
├─ 取 15 分钟线               135 天
│  └─ 按分钟槽位分组，加密 96 个槽（00:00 … 23:45）
│     每槽各自算 med / σ / 量能中位数（同样五步），各取该槽最近 90 个样本
│     21:30 槽 → { med: −0.00027908, σ: 0.00177838, vmed: 2,936,012 }
├─ 阈值（常数，不由数据定）     θz = 1.5   θv = 3.0    ← 加密
│                             θz_bar = 10  θv_bar = 3.0
└─ 全历史回放一次              502 根逐日重判 PV1、135 天逐根重判 PV5
   └─ 命中的写进 alertHistory  → Tab 2 的历史标记
```

#### σ 的五步，用 DOGE 真实日线走一遍

窗口 `2026-05-23 … 2026-08-20`，共 90 个收益率（不含被判定的当日 08-21）：

```
① 收盘价 → 收益率        r_i = C_i / C_{i-1} − 1              90 个
② 取中位数              med  = median(r)      = −0.00154419
③ 逐个取到 med 的距离    d_i  = |r_i − med|                    90 个
④ 距离的中位数           MAD  = median(d)      =  0.01016057   ← 中位绝对偏差
⑤ 校准成标准差量纲       σ    = 1.4826 × MAD   =  0.015064     ✅ 与产物一致
```

量能那一路只有一步：`vmed = median(V_{t−90} … V_{t−1}) = 442,978,529`。

**为什么是 median 不是 mean。** 第 ② 步和第 ④ 步都用中位数：一根 +13.8% 的
异动日进到窗口里，均值会被它拽高，于是**这只票经历一次大动之后，
下一次要更大才算异动**。中位数对单点不敏感，线不会被自己抬走。

**1.4826 从哪来。** 正态分布下 `MAD ≈ 0.6745σ`，取倒数就是 1.4826 ——
它把 MAD 换算回「标准差」那个量纲，好让 θz=1.5 读起来还是「1.5 个标准差」。
⚠️ 这个换算只在分布接近正态时成立，这正是 §九 的 ρ 检验存在的理由。

#### 槽位基线的五步，与日线同形但分组方式不同

```
① 135 天的 15 分钟 bar        加密约 12,960 根 / 美股约 3,510 根
② 按「时:分」分组             加密 96 组（00:00 … 23:45）· 美股 26 组（RTH）
③ 每组各取最近 90 个样本       21:30 这组 = 过去 90 天里所有 21:30 那一根
④ 组内走日线那同样的五步       med → |r−med| → MAD → ×1.4826 → σ
⑤ 量能同理                    vmed = 该组 90 个成交量的中位数

21:30 组 → { med: −0.00027908, σ: 0.00177838, vmed: 2,936,012, n: 90 }
```

⚠️ **为什么按槽位分组而不是混排。** 开盘和收盘那几根本来就比午盘活跃 ——
混在一起算，它们会被系统性地判成异常，而午盘的真异动反而过不了线。
按槽位分组之后，每根 bar 只和「历史上同一时刻的自己」比。

⚠️ **这一步在产物里核对不了。** 重建槽位基线要 135 天的分钟线，
而产物只保留最近 3 天（`symbols/<SYM>.json` 的 `intraday.bars`）——
上面这组数只能与 `baselines.DOGE.slotBaselines["21:30"]` 对齐，
无法像日线那样从原始数据逐步复现。日线那五步是**验证过能复现**的，这一步不是。

#### 三个读数怎么落到判定上

```
r     = 1,956,029,005 那天的收盘 / 前一天 − 1        = +0.13769
z     = (r − med) / σ = (0.13769 + 0.00154) / 0.015064 = 9.24
RVOL  = V / vmed = 1,956,029,005 / 442,978,529         = 4.42
```

⚠️ **θ 是常数,σ 是数据。** 线 = θ × σ —— 倍数固定,被乘的那个量滚动。
这是决策 #9 的直接后果:用固定阈值而非滚动分位,否则「异动」的定义会随市场自身漂移。

### 每天那一轮 · PV1

```
portfolio-watch-daily   10 0 * * *   每天 00:10 UTC
├─ 取 200 个自然日的日线（≈138 根美股 / 200 根加密，保证 ≥91 根）
├─ σ 重算              最近 90 个交易日，滚动，不含当日
├─ 今日读数
│    r     = 收盘 / 昨收 − 1     = +0.13769
│    z     = (r − med) / σ       = (0.13769 − (−0.0015)) / 0.015064 = 9.24
│    RVOL  = 今日量 / 90 日量中位数                                = 4.42
├─ 判定    |9.24| ≥ 1.5  ✅   ∧   4.42 ≥ 3.0  ✅   → 触发
└─ 落盘
     findings[]         一条 PV1
     scan[].price.line  θz × σ = 1.5 × 0.015064 = 0.0226   ← 页面「价格 vs 线」那一列
     alertHistory       整天替换 {d, signalId:"PV1", z, move, rvol, priceLine, volLine}
```

产物里那条记录长这样,上面每个数都对得上:

```json
{ "d": "2026-08-21", "signalId": "PV1", "z": 9.24, "move": 0.13769,
  "rvol": 4.42, "priceLine": 0.0226, "volLine": 3 }
```

### 每 15 分钟那一轮 · PV5

```
portfolio-watch-intraday   */15 * * * *
├─ 取当天的 15 分钟 bar（不重建基线 —— 每轮重拉 135 天太贵）
├─ 逐根判，用**该槽位自己**的线
│    21:30 那根:
│      r     = 收盘 / 前一根 − 1                  = +0.032852
│      z     = (0.032852 − (−0.00027908)) / 0.00177838 = 18.63
│      RVOL  = 57,266,600 / 2,936,012               = 19.50
│    判定  |18.63| ≥ 10  ✅   ∧   19.50 ≥ 3.0  ✅   → 触发
├─ 当天共 3 根过线      09:00（z −14.62）· 20:30（z 11.15）· 21:30（z 18.63）
└─ 落盘
     findings[]      逐根各一条
     alertHistory    整天**一条**，n=3，bars 记明细
```

```json
{ "d": "2026-08-21", "signalId": "PV5", "n": 3, "z": 18.63, "rvol": 19.5,
  "bars": [ { "slot": "09:00", "z": -14.62, "rvol": 27.74 },
            { "slot": "20:30", "z":  11.15, "rvol": 21.80 },
            { "slot": "21:30", "z":  18.63, "rvol": 19.50 } ] }
```

### 同一天，两套线：σ 差 8.5 倍，θ 反向补 6.7 倍，落到线上只差 1.3 倍

| | 日线 PV1 | 盘中 PV5 |
|---|---|---|
| σ 来自 | 最近 90 个**交易日**的日收益 | 最近 90 个**同槽位**样本（如所有 21:30） |
| σ 值 | 0.015064 | 0.00177838 |
| θ | 1.5 | 10 |
| **线（θ × σ）** | **2.26%** | **1.78%** |
| σ 更新 | **每天重算** | **冻结在初始化** |

⚠️ **两条线的量纲不同**：日线那条问「今天这一整天动了多少」，盘中那条问
「这 15 分钟动了多少」。

三个比值放在一起才看得懂这组数：

```
σ 之比      0.015064 / 0.00177838 = 8.47      日线的波动尺度是 15 分钟的 8.5 倍
θ 之比      10 / 1.5              = 6.67      盘中的倍数因此要调高
线之比      0.02260 / 0.01778     = 1.27      两条线最终落在相近的百分比上
```

θ_bar 取 10 而不是 1.5，正是为了抵消 σ 的量纲差；沿用 1.5 会让几乎每一根都过线。
而两条线最终只差 1.27 倍这件事本身有信息：**同样是 2% 上下的幅度，
发生在一整天里是常态，压缩在 15 分钟里就是异动。**

⚠️ **盘中 σ 是冻结的**，日线 σ 每天重算 —— 这不是疏漏而是取舍（见上方注释）。
代价是槽位基线越久越不准：DOGE 的日线 σ 在此后几天涨了 21.9%，
它的盘中 σ 大概率同向，而 PV5 还在用初始化那天的值，**偏向过度触发**。

## 五、持仓表上每一格怎么来

以 **NVDA · 2026-08-21** 为例（日线基准）：

| 表头 | 屏幕上 | 公式 | 代入 |
|---|---|---|---|
| 日常波动 · 90 个交易日 | `2.56%` | $\sigma^{\mathrm{rob}}_t$ | $1.4826\times1.7255\%$ |
| 价格 vs 线 · 左 | `-1.0%` | $r_t$ | 当日收益 $-0.9822\%$ |
| 价格 vs 线 · 右 | `±3.8%` | $\theta_z\cdot\sigma^{\mathrm{rob}}_t$ | $1.5\times2.5582\%=3.8372\%$ |
| 量能 vs 线 · 左 | `0.7×` | $\mathrm{RVOL}_t$ | $98{,}650{,}471 \div 143{,}170{,}646=0.689$ |
| 量能 vs 线 · 右 | `2.0×` | $\theta_v$ | **常数，查表得到，不由这只票算出** |
| 触发 | 空 | $|z_t|\ge1.5\wedge\mathrm{RVOL}\ge2.0$ | $|{-}0.367|<1.5$ → 不触发 |

对照 **DOGE 同一天**（加密，$\theta_v=3.0$）：

```
σ_rob = 1.4826 × 1.0161%          = 1.5064%      表上 1.51%
价格线 = 1.5 × 1.5064%            = ±2.2596%     表上 ±2.3%
r_t                                = +13.7691%    表上 +13.8%
z_t   = (13.7691 − (−0.1544)) / 1.5064 = +9.2429
RVOL  = 1,956,029,005 / 442,978,529    = 4.4156×  表上 4.4×
                                    |9.24| ≥ 1.5  ∧  4.42 ≥ 3.0  →  触发
```

⚠️ **价格线逐标的不同，量能线只有两个值。** 前者是这只票自己的波动算出来的，
后者是在 92 只美股 + 25 个币上验出来的常数。截图里那两列的形状本身就说明了这件事。

## 六、盘中卡上每一格怎么来

以 **DOGE · 2026-08-21 17:30 ET**（= 21:30 UTC）那根为例：

```
同一时刻样本        90 天（要求 ≥30）
该时刻收益中位 med   −0.0279%
σ_rob（该时刻）      0.1778%                     卡上「日常波动 90 天 0.18%」
盘中价格线          10.0 × 0.1778% = ±1.7784%    卡上「±1.8%」
这根收益 r_b        +3.2852%                     卡上「+3.3%」
z_bar               (3.2852 − (−0.0279)) / 0.1778 = +18.63   卡上「偏离倍数 +18.63」
该时刻量中位         2,936,012
这根量              57,266,600
RVOL_bar            57,266,600 / 2,936,012 = 19.5049×        卡上「19.5×」
这根收盘            0.09086                      卡上「$0.0909」
                    |18.63| ≥ 10.0  ∧  19.50 ≥ 3.0  →  触发
```

⚠️ **卡上的价格是这根 bar 自己的收盘（`trigger.barClose`），不是当日收盘。**
同一天 09:00 那根收在 $0.0834，当日收盘 $0.0916 —— 差 9.6%，方向还相反。

⚠️ **加密盘中的量能腿实测贡献为零** —— 过价格腿的 146 根里，量能腿一根都没剔掉
（美股剔掉 6.8–25.4%）。界面上不要对加密盘中说「双确认」。

## 七、逐标的投递上限

**它不改触发，只决定过线之后推不推手机。** 契约见
[output-schema §`signalGrades`](output-schema.md#signalgrades-是逐标的的投递上限与阈值无关)。

在这只标的的**全历史**上跑六步：

```
① 触发日   T = { t : |z_t| ≥ θz ∧ RVOL_t ≥ θv }        用与运行时同一套 θ 重跑
② 后 5 日波动   A_t = pstdev(r_{t+1}, …, r_{t+F})       总体标准差，先减这 5 天自己的均值
③ 基准     typ = median{ A_t : t ∈ 全部可评估日 }        ⚠️ 分母是全部日子，不是「非触发日」
④ 倍数     m_t = A_t / typ ,  t ∈ T
⑤ 区间     重采样 m（有放回、样本量不变）B 次取中位数
           CI = [第 2.5% 分位, 第 97.5% 分位]
⑥ 独立块   blocks = |{ t ∈ T : t − prev(t) ≥ F }|      间隔 < F 算同一块
```

可评估区间 $t\in[W{+}1,\ n{-}F)$ —— 头 90 天没基线，尾 5 天没前瞻窗。

$$\boxed{\ \mathrm{CI}_{\text{下界}}>1.0\ \ \wedge\ \ \mathrm{blocks}\ge5\ }$$

**1.0 就是「什么都没说」那条线** —— 倍数 $=1.0$ 意味着触发之后那五天和随便哪五天一样动荡。

| 判定 | 条件 | `maxDelivery` | 含义 |
|---|---|---|---|
| `usable` | 下界 > 1.0 ∧ 块 ≥ 5 | L1 | 推手机 |
| `effect_unclear` | 块 ≥ 5，下界 ≤ 1.0 | L2 | **测过了，没测出来** |
| `insufficient_sample` | 块 < 5 | L2 | **还没测够** |

### 算例

| 标的 | 全历史 | 触发日 | 块 | `typ` | 中位倍数 | 95% 区间 | 宽 | 上限 |
|---|---|---|---|---|---|---|---|---|
| NVDA | 4,993 | 178 | 110 | 0.019925 | 1.254 | [1.097, 1.368] | 0.271 | L1 |
| TSLA | 4,062 | 205 | 117 | — | 1.135 | [1.011, 1.265] | 0.254 | L1 |
| RIVN | 1,199 | 67 | 41 | 0.031170 | 1.299 | **[0.966**, 1.465] | 0.480 | L2 |
| SOFI | 1,313 | 61 | 41 | — | 1.137 | **[0.919**, 1.285] | 0.366 | L2 |

RIVN 的一个真实触发日 **2024-06-26**：后 5 日收益
`−1.83% · −7.26% · +3.73% · +6.97% · −1.61%` →
$A_t=0.049203$ → $m_t=0.049203/0.031170=1.579$。

⚠️ **RIVN 的点估计 1.299 高于 NVDA 的 1.254，却被压。**
若按点估计判，RIVN 会推手机而 NVDA 不推 —— **这就是判据不看点估计的原因**。
差别只在区间宽度：41 块 vs 110 块，同样的中位数，区间宽出近一倍，宽到把 1.0 包进去。

⚠️ **自助必须逐标的独立播种，$B$ 要大到噪声远小于「到 1.0 的距离」。**

```
共用一条随机流   实测把两只新标的挪到队首，TSLA 下界从 1.011 掉到 0.970 ——
                它自己一个数没变，只是别人插了队
```

## 八、回测判据 · 一条信号凭什么算通过

⚠️ **这一节的量在运行时一个都不用。** 判据的分子是触发**之后** 5 天的数据，
当天不存在 —— 告警规则没法自己评价自己，这正是回测存在的理由。

⚠️ **口径以 R28 定稿为准**（`backtest/scripts/pv-expanded/pv_engine.py`）。
`plan.md` §相对基准倍数 写的是被 R28 取代的旧式子，两处差在两个地方，见本节末。

### 分子与分母

```
V_t   触发日 t 的「之后 5 天有多动荡」
      = sqrt( mean( r_{t+1}² … r_{t+5}² ) )        ← 原始已实现波动，不除 σ

base  同一波动档里，平时有多动荡
      按 σ_rob 把全部交易日分成十分位
      每一档取该档内**非触发日**的 V 中位数
      剔除任一触发日的 ±5 天（前瞻窗重叠会污染基准）

倍数  = median over t∈T ( V_t / base[decile(t)] )   ← 逐触发比值的中位数
```

⚠️ **为什么不直接除以 σ，改成按 σ 分档匹配。** 触发本身会**机械地选中 σ 偏低的日子**
（阈值是 θ×σ，σ 小的日子更容易过线）——
NVDA 全局比值 0.844，分层之后层内是 0.98–1.03。除以 σ 修不掉这个选择效应，
按档匹配才是拿「同样波动档的平常日子」去比。

⚠️ **是「比值的中位数」，不是「中位数的比值」。** 两者不等：前者每个触发各自
与它所在档的基准比，后者会把不同档混在一起。

### 判据

```
通过 ⟺ 95% 自助区间下界 > 1.0   ∧   独立块数 ≥ 5
逐标的算，禁止跨标的池化
```

### 自助区间怎么抽

```
块      相邻触发间隔 < 5 个交易日 → 同一块
        （连着几天触发不是几条独立证据，是一件事）
重抽    有放回地抽「块」，不是抽单个触发日
        基准同步重抽：每一轮自助里，各档基准也从该档非触发日重抽一次
        —— 否则分母是定值，区间会偏窄
固定种子 SEED = 20260819 · NBOOT = 4000
下界    第 2.5 百分位
```

### 三个取值的含义

```
= 1.0    这条信号与随便挑一天没区别
> 1.0    触发之后确实比平时更动荡
≈ 1.49   PV1 的实测值
≥ 1.5    参考刻度 —— 本样本量能可靠分辨的量级，不是通过线
```

`backtest/universe/data/daily/AAPL.csv` —— **2018-01-02 … 2026-08-18，共 2168 根日线**。

#### ② 逐日滚动基线

算法与 §二 M2/M3 完全相同，差别只在**要对全部历史逐日重算一遍**。
以 2018-08-01 这天为例：

| | 值 | 来自 |
|---|---|---|
| 窗口 | 2018-03-23 … 2018-07-31，90 个收益率 | 这天之前的 90 天，**不含当天** |
| med | +0.00122841 | 90 个收益率的中位数 |
| MAD | 0.00663899 | 90 个 \|r − med\| 的中位数 |
| **σ** | **0.009843 = 0.98%** | 1.4826 × MAD |
| 量能中位数 | 92,890,432 | 90 天成交量的中位数 |
| 当天成交量 | 271,742,564 | 2018-08-01 那天的 volume，**不在窗口里** |

这天自己的读数：

```
r    = +0.05724                                    当天涨 5.72%
z    = (0.05724 − 0.00123) / 0.009843 = 5.69
RVOL = 271,742,564 / 92,890,432       = 2.93
价格线 = 1.5 × 0.98% = 1.48%   而当天动了 5.72%

判定   价格腿 |5.69| ≥ 1.5   ✅
       量能腿  2.93  ≥ 2.0   ✅        → 这天触发
```

**这天就是下面 61 次里按时间序的第 1 次**，本节往下一直用它做例子：
④ 算它之后 5 天的 V · ⑥ 算它的比值 · ⑦ 它和次日 2018-08-02
（z = 2.88 · RVOL = 2.69，也触发）间隔 1 天，同属块 0。

2168 天里 **2102 天算得出读数**：开头 61 天窗口不够，结尾 5 天缺前瞻窗（见 ⑤）。

#### ③ 找触发日

```
|z| ≥ 1.5   ∧   RVOL ≥ 2.0        触发式见 §三 PV1
```

→ **61 次**。其中 |z| 最大的三次：

| 触发日 | z | RVOL |
|---|---|---|
| 2025-04-09 | +9.41 | 4.00 |
| 2020-03-16 | −9.17 | 2.74 |
| 2025-04-03 | −7.62 | 2.29 |

⚠️ 这个 61 的含义是「**历史上有 61 天，按 ②③ 的逻辑会响**」。
回测不预测 —— 它把规则拿回过去重跑，看它当年在哪些日子响，再逐日检查那之后发生了什么。

#### ④ 每次触发之后有多动荡

仍以 2018-08-01 为例，取它**之后**的 5 个交易日：

| 日期 | 收盘 | 收益率 r | r² |
|---|---|---|---|
| 2018-08-02 | 51.85 | +0.02881 | 0.00083011 |
| 2018-08-03 | 52.00 | +0.00289 | 0.00000835 |
| 2018-08-06 | 52.27 | +0.00518 | 0.00002682 |
| 2018-08-07 | 51.78 | −0.00942 | 0.00008872 |
| 2018-08-08 | 51.81 | +0.00068 | 0.00000046 |
| | | **Σr²** | **0.00095446** |

```
mean = 0.00095446 / 5 = 0.00019089
V    = sqrt(0.00019089) = 0.01382        ← 这天的分子
```

用平方所以**不分涨跌** —— 问的是「动得厉害不厉害」，不是「往哪动」。

⚠️ **只从 t+1 起。** 触发日那根大 bar 正是让它触发的原因，算进去就是用结论证明结论。

61 次全部可算，没有一次的 t+5 越界。

#### ⑤ 造基准：「平时」有多动荡

**先划出哪些日子能用。** 一天要进后面的计算，得同时算得出 σ 和 V：

```
2168 天
 −  61 天   开头，凑不够 60 个收益率（第 1 天没有前收）
 −   5 天   结尾，之后不足 5 天，V 算不出
 ────────
   2102 天  可用
```

⚠️ 两头排除的理由不同：**开头缺过去的数据，线上也不出读数;
结尾缺未来的数据，线上照常告警，只是这次回测评不了分。**

**按 σ 切十档。** 把 2102 天的 σ 排序，在 10%…90% 切九刀：

```
最小 0.74% │0.97│1.06│1.15│1.22│1.32│1.48│1.74│1.95│2.20│ 最大 2.83%
           档0  档1  档2  档3  档4  档5  档6  档7  档8  档9
```

**剔掉被污染的日子。** 离任一触发不到 5 天的日子，前瞻窗与触发的重叠，
留在分母里等于把触发后的动荡算进「平常」。61 次触发 × ±5 天，去重后盖住 **375 天**。

**每档取中位。** 一档之内，把触发日和被污染的日子都拿掉，
剩下的日子取它们 V 的中位数：

```
for i in 0..9:
    该档 = 所有 σ 落在第 i 档的可用日
    干净 = 该档里 · 不是触发日 · 也不在污染集合里的日子
    base[i] = median( V[t] for t in 干净 )
```

⚠️ **取的是 V 的中位数，不是 σ 的。** σ 只用来决定这天进哪一档，
进档之后 σ 就退场了 —— 一档之内比的是「这些日子后来五天实际有多动荡」。
分档只是为了让比较双方的波动水平相当，档内的数值全部来自 V。

|---|---|---|---|---|---|---|
| 0 | 0.74–0.97% | 210 | 5 | 27 | 178 | 0.01276 |
| 1 | 0.97–1.06% | 210 | 5 | 41 | 164 | 0.01121 |

| 3 | 1.15–1.22% | 213 | 9 | 61 | 143 | 0.01168 |
| 4 | 1.23–1.32% | 207 | 7 | 27 | 173 | 0.01151 |

| 9 | 2.20–2.83% | 212 | **0** | 0 | 212 | 0.01742 |

**档 5 的 base 从 0.01133 是这么来的。** 三段相加必须等于该档天数：

```

144 个 V 从小到大排，偶数个取中间两个的平均：
  0.00266 … │ 第 72 个 0.011283 │ 第 73 个 0.011376 │ … 0.02899
                    (0.011283 + 0.011376) / 2 = 0.011330
```

⚠️ 零成本自检：各档污染数相加 27+41+28+61+27+52+19+35+24+0 = **314**，
加上 61 个触发日正好 **375**，与上一步「去重后盖住 375 天」对得上。

⚠️ **档 9 的污染数是 0，不是漏算。** σ 是 90 天滚动的，相邻日子的 σ 几乎一样，
所以一个触发日的 ±5 天基本落回它自己那一档。档 9 一次触发都没有，
它的污染数因此也是 0。同理档 3 的 9 次触发盖住了本档 61 天，
接近 9×10 的上限，说明那 9 次挤在同一段行情里。

⚠️ **切点归哪一档要写死。** 上表用「线性插值分位 + 严格小于」，即切点本身归上面那一档。
改成 `≤`（切点归下面那一档）后各档天数变成 212/210/210/209/211/210/210/209/215/206，
倍数从 **2.0963** 变成 **2.0828**。差 0.6%，不改判定，
但这是口径漂移的典型入口 —— 两处实现必须写同一条规则。

⚠️ **每档天数都是 ~210，触发数却从 0 到 14。** 分母均匀，分子完全不是 ——
这就是「不能拿全体当基准」的直接证据。实测不分档时倍数是 **1.904**，分档后 **2.096**，差 10%。

⚠️ **「触发数」和「触发占比」不进任何计算**，只用来看分布是否均匀。

后者会让 2 次触发的档和 14 次触发的档权重相同（实测 1.772，差 15%）。
一次触发一票。

⚠️ **base 是换算，不是对比对象。** 除完之后 61 个数已经各自扣掉了波动水平，
所以能放进同一个中位数 —— 就像先把英寸都换成厘米，再求这 61 个人的身高中位。

#### ⑦ 整块自助：区间从哪来

**为什么点估计不够。** 2.096 高度依赖一个事件：

```
全部 61 次                              中位 2.096
去掉 2020-02-24 … 03-24 那 15 次        中位 1.637   ← 掉 22%
```

一个事件占了 61 次里的 25%。光看 2.096，说不出「这条规则的本事」和「碰上那一周」各占多少。

**先合并挨着的触发。** 61 次触发**不是 61 份独立证据**。
2020-02-24 到 03-24 那 15 次是同一件事：如果 AAPL 那个月没崩，
这 15 份证据会**一起**消失，不是一份一份消失。
所以真正的样本量不是 61，是把它们合并之后的**事件数**。

相邻两次触发间隔不到 5 个交易日的，算同一段行情，合成一个**块**。
一个块就是一件独立的事，一个块里含几次触发，就是这个块的**大小**。
判据里「独立块数 ≥ 5」数的也是块，不是触发日。
**5 这个数不是随手定的**，它等于前瞻窗长 FWD = 5。间隔 4 时，
两次触发的 `[t+1, t+5]` 窗口重叠 1 天；间隔 5 时刚好不重叠。
所以「不到 5 个交易日」的准确含义是**前瞻窗有任何重叠就算同一件事**。

把 61 个触发日按时间排好，逐个看它与上一次隔了几个交易日。前 16 个：

序列开头那个 `2` 就是 ② 用的例子：2018-08-01 与 08-02 只隔 1 天，同属一块。

**重抽 4000 轮。** 2.096 是「AAPL 在 2018–2026 这段历史里，
恰好遇到这 31 段行情」算出来的。换一段历史会是多少？没法真的重演，
自助法用抽样来模拟一段「平行历史」：

```
每一轮：
  1  从 31 个块里有放回地抽 31 次          抽样的单位是「块」
  2  把抽中的块展开成触发                  抽中一个块，它含的触发全部进来
                                          同一个块抽中两次就整批进来两遍
  3  对展开后这些触发的比值取中位           求中位的单位是「触发」
重复 4000 轮
```

⚠️ **抽的是块，取中位的是触发，两者不是同一个单位。**
块不是一个统计量，它是一个打包 —— 整包进、整包出，包里的比值一个不少地
散进那一堆去，然后对那一堆取中位。**「块的中位数」这个东西不存在。**

整条链上中位数只出现在两个地方：base 是某一档干净日子的 V 的中位数（见 ⑤），
倍数是一堆比值的中位数（见 ⑥）。每次触发本身只有**一个比值**，不是中位数。

关键在**有放回**：不放回的话每轮抽到的还是原来那 31 个块，一点变化都没有。
每轮同时把每档 base 也从该档净化后的日子重抽一次
（不抖的话分母是定值，区间会偏窄）：

| 轮次 | 抽到的不重复块 | 这轮共几次触发 | 块10 被抽中几回 | 这轮的中位 |
|---|---|---|---|---|
| 第 1 轮 | 19 / 31 | 53 | 0 | 1.960 |
| 第 2 轮 | 23 / 31 | 55 | 1 | 1.973 |
| 第 3 轮 | 21 / 31 | 76 | 1 | 2.468 |
| 第 4 轮 | 20 / 31 | 52 | 0 | 1.893 |
| 第 5 轮 | 23 / 31 | 83 | 2 | 2.551 |
| 第 6 轮 | 18 / 31 | 78 | 2 | 2.531 |

⚠️ **`results-pv.md` 里 AAPL 那个 2.02 是旧口径的数字** ——
R28 定稿只重跑了 XOM / SOFI / NVDA / KO / TSLA 五只，AAPL 不在其中。
两个都列在这里，是因为拿新实现去核旧数字必然对不上，
而那种对不上看起来和「算错了」一模一样。

**读法**：AAPL 触发之后那 5 天的波动，是它平常日子的 2.0 倍；
即便按最不利的抽样估计，也还有 1.32 倍。

⚠️ **不确定性来自外推，不来自计算。** 同一段数据 + 同一条规则永远给同样的 61 天。
判据要回答的是「这条规则以后还管不管用」，而「以后」还没发生。

自助法用「手上这 31 个块 ≈ 这条规则会遇到的各种情形」这个假设，把那个不确定性量出来。

## 九、分布可用性 ρ

$$\rho=\frac{1}{|Z|}\big|\{\,t: |z_t|\ge\theta_z\,\}\big|,\qquad Z=\text{近 504 个交易日}$$

有效样本 $<250$ 日 → $\rho=\varnothing$，走 PV4 覆盖标注。

```
ρ < 2%          线太紧，这只票几乎不可能触发   → 停用，界面标覆盖不足
2% ≤ ρ ≤ 40%    正常
ρ > 40%         线形同虚设                    → 降 Warning
```

⚠️ **上界是 40%，不是 60%。** 两个值曾同时存在，连本节的三行里都自相矛盾
（40–60% 既算「正常」又要「降 Warning」）。判据来源是 PV1 的降级规则。

⚠️ **停用与降级是两件事。** $\rho<2\%$ 是**算不出可信的量**，
而降级投递是「算得出但证据弱」—— 算不出的量在任何层级都不该显示。

主账本实测 12.90%–19.44%，十只全在带内。
